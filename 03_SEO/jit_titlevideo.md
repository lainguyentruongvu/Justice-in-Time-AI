# jit_titlevideo

Version:
1.0

Status:
Stable

Dependencies:

jit_CORE

jit_BRAND

jit_STYLE

jit_RULES

========================================

# Purpose

Generate high CTR YouTube video titles.

Optimize for humans first.

Algorithm second.

========================================

# Input

Script

Case Summary

Hook

Key Evidence

Main Twist

========================================

# Output

10 Optimized Titles

========================================

# Primary Goal

Maximize:

CTR

Curiosity

Emotional Impact

Searchability

========================================

# Title Philosophy

Sell the moment.

Not the case.

Focus on the strongest scene.

Not the entire story.

========================================

# Preferred Structure

Character

↓

Belief / Action

↓

Evidence / Twist

========================================

# Example

Teacher Thinks She Fooled Everyone — Then Her Own Texts Surface

========================================

# Title Rules

Under 100 characters.

Prefer 70–95.

Easy to read.

Easy to understand.

One main idea.

========================================

# Audience

American

45–70

========================================

# Preferred Opening

Teacher

Mother

Teen

Beauty Queen

Girlfriend

Husband

Doctor

Police Officer

Judge

Killer

Neighbor

Never use names unless requested.

========================================

# Emotional Triggers

Lied

Smiled

Believed

Thought

Claimed

Celebrated

Ignored

Forgot

Never Knew

========================================

# Preferred Ending

Then the Video Plays

Then the Jury Speaks

Then the DNA Returns

Then the Judge Responds

Then Her Phone Changes Everything

Then the Truth Comes Out

========================================

# Avoid

Generic summaries

Spoilers

Clickbait without payoff

Too many adjectives

Long titles

========================================

# Quality Checklist

✓ Under 100 characters

✓ Cinematic

✓ Curiosity

✓ Emotional

✓ Easy to scan

✓ High CTR potential

Rewrite weak titles.

========================================

# Success

A viewer should immediately want to know:

"What happened next?"
