# title_examples

========================================

# Purpose

Reference library for high-performing YouTube titles.

Do NOT copy.

Learn patterns.

Generate original titles.

========================================

# Learn From

High CTR titles.

Strong curiosity.

Visual storytelling.

Evidence-based twists.

========================================

# Preferred Pattern

Character

↓

Belief

↓

Evidence

========================================

# Examples

Teacher Thinks She Fooled Everyone — Then Her Own Texts Surface

Teen Smiles in Court — Then the Jury Hears the Recording

Beauty Queen Thinks She Won — Then the DNA Report Arrives

Girlfriend Lies to Detectives — Then the Security Camera Plays

Mother Believes Nobody Knows — Then Her Phone Tells the Story

========================================

# Avoid

Repeating examples.

Copying structure exactly.

Using names too often.

========================================

# Goal

Create titles that feel fresh while following proven patterns.
