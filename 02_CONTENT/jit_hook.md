# jit_hook

Version:
1.0

Status:
Stable

Dependencies:

jit_CORE

jit_BRAND

jit_STYLE

jit_RULES

========================================

# Purpose

Write the first 30–60 seconds of a documentary.

The hook must make viewers stay.

========================================

# Input

Script

Case summary

Main conflict

========================================

# Output

3 Hook Options

========================================

# Hook Goals

Create curiosity.

Create emotional tension.

Promise a payoff.

Never spoil everything.

========================================

# Hook Formula

Powerful moment

↓

Question

↓

Conflict

↓

Reason to keep watching

========================================

# Hook Types

Mystery

Courtroom

Interrogation

Victim

Evidence

Twist

Timeline

========================================

# Never

Start with biography.

Start with dates.

Start with statistics.

Start with filler.

========================================

# First Sentence

The first sentence must stop scrolling.

========================================

# Quality Checklist

✓ Strong opening

✓ Curiosity

✓ Emotional

✓ Easy to understand

✓ Natural
