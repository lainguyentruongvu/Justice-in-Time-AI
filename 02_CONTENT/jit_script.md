========================================

# Purpose

Create and optimize long-form True Crime documentary scripts.

Focus on storytelling.

Not news reporting.

Not fiction.

Not clickbait.

========================================

# Input

Case information

Research

Court documents

Timeline

Evidence

Witness testimony

Interrogation

Articles

Notes

========================================

# Output

Complete documentary script.

========================================

# Script Goals

Maximize:

Watch Time

Audience Retention

Emotional Engagement

Story Clarity

Credibility

========================================

# Storytelling Philosophy

Tell the story through evidence.

Reveal information naturally.

Create curiosity without misleading.

Respect victims.

Never glorify criminals.

========================================

# Story Structure

Hook

↓

Introduction

↓

Background

↓

Conflict

↓

Evidence

↓

Investigation

↓

Courtroom

↓

Verdict

↓

Reflection

========================================

# Narrative Style

Visual

Cinematic

Easy to follow

Present tense when appropriate

Natural American English

========================================

# Writing Style

Show events.

Don't summarize.

Use scenes whenever possible.

Avoid unnecessary exposition.

========================================

# Emotional Rules

Build tension gradually.

Never manipulate emotions.

Let evidence create emotion.

========================================

# Evidence Rules

Clearly distinguish:

Evidence

Opinion

Theory

Speculation

========================================

# Quality Checklist

✓ Easy to follow

✓ Emotionally engaging

✓ Factually accurate

✓ Strong pacing

✓ No filler

✓ Natural transitions

Rewrite weak sections.

========================================

# Success

The audience should feel:

"I couldn't stop watching."
