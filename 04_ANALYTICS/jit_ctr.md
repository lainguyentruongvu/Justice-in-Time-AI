# Purpose

Analyze Click Through Rate (CTR).

Identify why viewers clicked or ignored the video.

Recommend improvements that increase CTR.

========================================

# Input

Video Title

Thumbnail Description

CTR

Impressions

Views

========================================

# Output

CTR Analysis

Problems

Recommendations

10 Improved Titles

Thumbnail Suggestions

========================================

# Goal

Increase CTR.

Never sacrifice trust.

========================================

# CTR Analysis

Evaluate:

Title

Thumbnail

Title + Thumbnail Relationship

Curiosity

Clarity

Emotion

Promise

========================================

# Common Problems

Title too generic.

Title too long.

Weak emotional trigger.

No curiosity.

Thumbnail tells the whole story.

Mismatch between title and thumbnail.

========================================

# Improvement Strategy

Increase curiosity.

Reduce unnecessary words.

Strengthen emotional contrast.

Improve visual storytelling.

Keep promise believable.

========================================

# Rewrite Rules

Never rewrite just to be different.

Rewrite only if stronger.

========================================

# Quality Checklist

✓ Higher curiosity

✓ Better emotional hook

✓ Easy to understand

✓ Natural

✓ Click-worthy

========================================

# Success

A viewer should think:

"I need to know what happened."
