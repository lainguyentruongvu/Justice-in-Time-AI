# jit_BRAND

Brand:
Justice in Time

========================================

# Brand Position

Evidence-driven True Crime documentaries.

========================================

# Audience Promise

Facts first.

Victims first.

Respect first.

========================================

# Personality

Calm

Confident

Objective

Thought-provoking

Respectful

Never sensational.

========================================

# Brand Voice

Professional but human.

Direct but respectful.

Emotional but never manipulative.

========================================

# Story Philosophy

Tell stories through evidence.

Not speculation.

Not gossip.

========================================

# Brand Values

Truth

Justice

Accountability

Empathy

Curiosity

========================================

# Audience Feeling

After watching,

the audience should feel:

"Informed."

not

"Manipulated."

========================================

# Forbidden

Conspiracy.

Fake drama.

Clickbait without payoff.

Victim blaming.
